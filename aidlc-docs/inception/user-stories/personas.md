# User Personas

## Persona 1: The Indie Game Designer (Primary)
**Name**: Alex Chen  
**Role**: Solo indie game developer / game designer  
**Technical Level**: Intermediate — comfortable with software tools, limited coding experience  
**Goals**:
- Create point-and-click adventure games without writing engine code
- Rapidly prototype game scenes and test event interactions
- Manage all game assets in one place

**Pain Points**:
- Existing tools are too complex or require programming knowledge
- Asset management is disorganized across multiple folders
- Hard to visualize how events will play out in-game

**Usage Pattern**: Primary daily user of all editor modules

---

## Persona 2: The Level Designer
**Name**: Sam Rivera  
**Role**: Level designer on a small indie team  
**Technical Level**: Low-to-intermediate — strong creative skills, minimal technical background  
**Goals**:
- Design individual scenes and stages without touching code
- Quickly set up goals and win conditions for each stage
- Iterate on scene layouts with drag-and-drop ease

**Pain Points**:
- Gets blocked waiting for programmers to wire up events
- Needs visual feedback on what event triggers will do

**Usage Pattern**: Heavy use of Scene Editor, Stage Editor, Goal Editor; lighter use of Event Editor

---

## Persona 3: The Artist / Animator
**Name**: Jordan Kim  
**Role**: 2D artist and animator on an indie team  
**Technical Level**: Low — expert in art tools, minimal IDE experience  
**Goals**:
- Import artwork and sprite sheets quickly
- Set up animations without needing developer help
- Preview how cursor and UI graphics look in context

**Pain Points**:
- Struggles with technical setup of sprite frames and animation timing
- Needs immediate visual feedback on assets

**Usage Pattern**: Primary user of Assets Manager, Sprite Manager, Cursor Editor, UI Editor

---

## Persona 4: The Narrative Designer
**Name**: Morgan Ellis  
**Role**: Writer and narrative designer  
**Technical Level**: Low — expert writer, no programming background  
**Goals**:
- Define game logic and event flows through a visual interface
- Create dialogue events and conditional story branches
- Set up settings like text speed and difficulty

**Pain Points**:
- Cannot write code; needs purely visual event editing
- Wants to see the full event flow for a scene at a glance

**Usage Pattern**: Heavy use of Event Editor, Settings Editor, Title Screen Editor
