# User Stories

## Epic 1: Scene Editing

**US-001**: As a game designer, I want to open a visual canvas and place background images so that I can set the visual context for each game scene.

**US-002**: As a game designer, I want to drag and drop sprites onto the scene canvas so that I can populate scenes with interactive objects and characters.

**US-003**: As a game designer, I want to select objects on the canvas and adjust their position, size, and z-order so that I can precisely lay out the scene.

**US-004**: As a game designer, I want to navigate between scenes using a scene list panel so that I can quickly switch context while building my game.

**US-005**: As a game designer, I want to zoom and pan the scene canvas so that I can work on detailed areas of large scenes.

---

## Epic 2: Event Editing

**US-006**: As a game designer, I want to attach event triggers to scene objects so that clicking or hovering on an object causes something to happen in the game.

**US-007**: As a game designer, I want to chain multiple actions to an event (play sound, show text, navigate to scene) so that I can create rich interactive sequences.

**US-008**: As a narrative designer, I want to add conditional logic to events (if variable = X then do Y) so that story branches respond to player decisions.

**US-009**: As a narrative designer, I want to view all events on a scene object in a list so that I can understand and modify the object's behavior.

**US-010**: As a game designer, I want to create global events that fire across all scenes so that consistent game rules apply everywhere.

---

## Epic 3: Asset Management

**US-011**: As an artist, I want to import image files (PNG, JPG, GIF, SVG) into the project so that I can use them in my scenes.

**US-012**: As an artist, I want to import audio files (MP3, OGG, WAV) so that I can add sound effects and music to events.

**US-013**: As an artist, I want to browse a categorized asset library (images, audio, video) so that I can quickly find and use the right asset.

**US-014**: As an artist, I want to preview assets before placing them so that I select the correct one without trial and error.

**US-015**: As a game designer, I want to drag assets from the library directly onto the scene canvas so that placing artwork is fast and intuitive.

---

## Epic 4: UI Design

**US-016**: As a game designer, I want to add dialogue boxes, inventory panels, and HUD elements to the game UI so that players have the expected adventure game interface.

**US-017**: As an artist, I want to style UI elements (font, color, size, border) so that the game UI matches the visual theme.

**US-018**: As a game designer, I want to preview the UI layout in context of a scene so that I can validate the visual design before testing.

---

## Epic 5: Sprite & Animation

**US-019**: As an artist, I want to import a sprite sheet and slice it into individual frames so that I can define animations from existing artwork.

**US-020**: As an artist, I want to define named animation sequences (walk, idle, talk) and preview their playback so that I can verify timing and frame order.

**US-021**: As a game designer, I want to assign animations to sprite objects in a scene so that characters and objects can move and animate during gameplay.

---

## Epic 6: Game Settings

**US-022**: As a game designer, I want to define global game metadata (title, author, version) so that the game is properly identified.

**US-023**: As a game designer, I want to configure player-adjustable settings (difficulty, volume, text speed) so that players can customize their experience.

**US-024**: As a game designer, I want to set the starting scene of the game so that the game launches at the correct point.

---

## Epic 7: Title Screen

**US-025**: As a game designer, I want a default title screen with title text and standard menu buttons (New Game, Load Game, Settings, Quit) so that my game has a professional starting point.

**US-026**: As an artist, I want to customize the title screen background and button styling so that the title screen matches my game's aesthetic.

**US-027**: As a game designer, I want to create additional menu dialogs (Credits, Options) accessible from the title screen so that the game has a complete main menu.

---

## Epic 8: Stage Management

**US-028**: As a game designer, I want to see a list of all game stages so that I can navigate and organize the game's progression.

**US-029**: As a game designer, I want Stage 1 to be created automatically when I start a new project so that I can begin adding scenes immediately.

**US-030**: As a level designer, I want to add, rename, reorder, and delete stages so that I can structure the game's progression flow.

**US-031**: As a level designer, I want to associate scenes with a specific stage so that stage progression is logically organized.

---

## Epic 9: Goal Definition

**US-032**: As a level designer, I want to define completion conditions for each stage (e.g., collected item X, visited scene Y) so that the game knows when a stage is complete.

**US-033**: As a level designer, I want to combine multiple conditions with AND/OR logic so that complex goal requirements can be expressed.

**US-034**: As a game designer, I want to specify what happens when a stage is completed (advance stage, show cutscene, end game) so that game progression is automatic.

---

## Epic 10: Cursor Customization

**US-035**: As an artist, I want to upload a custom image for the game cursor so that the cursor matches the game's visual style.

**US-036**: As an artist, I want to define multiple cursor states (default, hover, interact) so that the cursor provides visual feedback to the player.

**US-037**: As an artist, I want to preview the cursor in a simulated game view so that I can confirm it looks correct before finalizing.
