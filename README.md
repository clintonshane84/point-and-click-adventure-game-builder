# Point and click adventure game builder
A nadventure game builder that allows the user to build event based adventure games. The point and click adventure game builder will feature:

1. Scene editor (the main window used to build the game scenes)
2. Event editor (manages the creation and editing of events in the game)
3. Assets manager (import and make locally available assets for the game like image, audio and video files)
4. UI editor (allows the user to create a custom UI/UX other than the editors default)
5. Sprite manager (animation and sprite management library for the game)
6. Settings editor (create settings that a player can adjust for the game, i.e. game speed, difficulty, and so on)
7. Title screen editor (provide a default title screen with default content but allow the user can create there own title screen, which includes additional menu dialogs to adjust settings and inner options from the main menu)
8. Stage editor. Create stages for the game, starting by default with level 1 already created.
9. Goal editor. Define conditions for completing the stage per stage level.
10. Cursor editor. Allows the user to create a custom graphic for the mouse cursor in game.
